CÓMO SUBIR A GITHUB
1. Descomprimí este zip.
2. En GitHub, abrí tu repo → Add file → Upload files.
3. Arrastrá la carpeta "api", "vercel.json" y ".vercelignore" (reemplaza los archivos existentes, mantiene la estructura de carpetas).
4. Commit changes. Vercel despliega solo (si no, Vercel → Deployments → Redeploy).

PASOS EXTRA (una sola vez, si no los hiciste):
- Stripe → Webhooks → tu endpoint /api/stripe → agregar evento "checkout.session.expired".
- Vercel → Settings → Environment Variables: CRON_SECRET (cualquier texto largo).
